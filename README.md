## DevBoard

**AIとの開発を、ひとつのボードで。**

タスクを書いてAIに依頼し、作業の経過・質問・仕上がりをまとめて確認できるMacアプリです。複数のプロジェクトやタスクを並行して進められます。

macOS 15 以降

**[最新版をダウンロード（0.40.0）](https://github.com/ymasaki/public-releases/releases/download/local.masaki.DevBoard-0.40.0-1603/local.masaki.DevBoard-0.40.0-1603.zip)**

ZIP を開き、DevBoard.app を「アプリケーション」フォルダへ移してください。以降の新しい版はアプリ内でお知らせします。

## DropSync

Dropbox と Mac のフォルダを同期するメニューバーアプリです。

macOS 14.0 以降（arm64）

**[最新版をダウンロード（0.1.0）](https://github.com/ymasaki/public-releases/releases/download/com.yamamoto.DropSync-0.1.0-48/com.yamamoto.DropSync-0.1.0-48.zip)**
